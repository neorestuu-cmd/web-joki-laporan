FAQ

Pertanyaan yang Sering Ditanya

Apakah laporan yang dihasilkan sudah sesuai standar sekolah? +
Ya! Template laporan kami dibuat mengikuti standar umum laporan PKL SMK/SMA di Indonesia. Sudah mencakup 4 BAB lengkap: Pendahuluan, Profil Perusahaan, Kegiatan PKL, dan Penutup, plus Kata Pengantar dan Daftar Isi.
Berapa lama proses generate laporan? +
Sangat cepat! Setelah pembayaran dikonfirmasi, laporan PKL lengkap kamu akan siap dalam hitungan detik. Tidak ada waktu tunggu yang lama.
Apa saja format yang bisa didownload? +
Untuk paket Basic: PDF saja. Untuk paket Pro dan Premium: DOCX (Word, bisa diedit) dan PDF (siap cetak). Format DOCX sangat berguna jika kamu ingin melakukan penyesuaian lebih lanjut.
Apakah data saya aman? +
Tentu! Data kamu disimpan secara lokal di browser-mu dan tidak dikirim ke server pihak ketiga. Privasi kamu adalah prioritas kami.
Bagaimana jika laporan tidak sesuai ekspektasi? +
Paket Premium mendapat 2x hak revisi. Untuk paket Basic dan Pro, kamu bisa mengedit file DOCX sesuai kebutuhan. Kami juga selalu berusaha meningkatkan kualitas template kami.
Metode pembayaran apa saja yang diterima? +
Kami menerima QRIS (semua e-wallet), Transfer Bank (BCA, Mandiri, BRI, BNI), dan Dompet Digital (DANA, OVO, GoPay, ShopeePay).
